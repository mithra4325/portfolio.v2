Task 03: Voice Control with Google Assistant and IFTTT

Overview

This task switches an appliance with a voice command. A spoken phrase to Google Assistant triggers an IFTTT applet. The applet sends ON or OFF to an Adafruit IO feed. The ESP32 is subscribed to that feed and drives a relay module that switches the appliance.

The data flow is: Voice command, Google Assistant, IFTTT, Adafruit IO feed, ESP32, relay, appliance.

Objective

  • Create IFTTT applets that turn a Google Assistant phrase into an Adafruit IO feed update.
  • Subscribe the ESP32 to the feed and drive a relay.
  • Switch an appliance on and off using voice only.

Components

  • ESP32 development board
  • Relay module [[FILL: number of channels, e.g. 4-channel with optocoupler]]
  • Appliance or bulb [[FILL: what you switched]]
  • Breadboard and jumper wires
  • 5 V supply for the relay module
  • Google Assistant on a phone
  • IFTTT and Adafruit IO accounts

Work

  1. Created a feed in Adafruit IO named "bulb" [[FILL: change if you used another name]]. This is the feed the ESP32 listens to.
  2. Created the first IFTTT applet. The trigger is Google Assistant, "Say a simple phrase", with the phrase [[FILL: your ON phrase]]. The action is Adafruit IO, "Send data to Adafruit IO", with the feed bulb and the data ON.
  3. Created the second applet with the phrase [[FILL: your OFF phrase]] and the data OFF.
  4. Wired the relay module. VCC goes to 5 V, GND goes to ground, and IN1 goes to GPIO 23 of the ESP32. The appliance is connected through the COM and NO terminals of the relay, so the relay works as the switch in the appliance line.
  5. Wrote the sketch. The ESP32 connects to Wi-Fi, connects to Adafruit IO over MQTT and subscribes to the bulb feed. When ON arrives it energises the relay. When OFF arrives it releases the relay.
  6. The relay module is active-LOW, so the pin is driven LOW to switch the relay ON and HIGH to switch it OFF. The pin is set to OFF as soon as the program starts so the appliance does not switch on during boot.
  7. Said the ON phrase to Google Assistant. IFTTT updated the feed, the ESP32 received ON and the relay clicked on. Repeated with the OFF phrase.

Code

File: ESP32_Voice_Relay.ino
#include <WiFi.h>
#include "Adafruit_MQTT.h"
#include "Adafruit_MQTT_Client.h"

#define WLAN_SSID      "YOUR_WIFI_NAME"
#define WLAN_PASS      "YOUR_WIFI_PASSWORD"
#define AIO_SERVER     "io.adafruit.com"
#define AIO_SERVERPORT 1883
#define AIO_USERNAME   "YOUR_AIO_USERNAME"
#define AIO_KEY        "YOUR_AIO_KEY"

const int RELAY_PIN = 23;   // relay IN1
const int RELAY_ON  = LOW;  // most relay modules are active-LOW
const int RELAY_OFF = HIGH;

WiFiClient client;
Adafruit_MQTT_Client mqtt(&client, AIO_SERVER, AIO_SERVERPORT, AIO_USERNAME, AIO_KEY);
Adafruit_MQTT_Subscribe bulbFeed = Adafruit_MQTT_Subscribe(&mqtt, AIO_USERNAME "/feeds/bulb");

unsigned long lastPing = 0;

void MQTT_connect() {
  if (mqtt.connected()) return;
  Serial.print("Connecting to MQTT... ");
  int8_t ret;
  uint8_t retries = 3;
  while ((ret = mqtt.connect()) != 0) {
    Serial.println(mqtt.connectErrorString(ret));
    mqtt.disconnect();
    delay(5000);
    if (--retries == 0) ESP.restart();
  }
  Serial.println("connected");
}

void setup() {
  Serial.begin(115200);
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, RELAY_OFF);   // relay off at start

  WiFi.begin(WLAN_SSID, WLAN_PASS);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi connected");

  mqtt.subscribe(&bulbFeed);
}

void loop() {
  MQTT_connect();

  Adafruit_MQTT_Subscribe *sub;
  while ((sub = mqtt.readSubscription(1000))) {
    if (sub == &bulbFeed) {
      String msg = (char *)bulbFeed.lastread;
      msg.trim();
      msg.toUpperCase();
      Serial.print("Voice command received: ");
      Serial.println(msg);
      digitalWrite(RELAY_PIN, msg == "ON" ? RELAY_ON : RELAY_OFF);
    }
  }

  if (millis() - lastPing > 30000) {
    lastPing = millis();
    if (!mqtt.ping()) mqtt.disconnect();
  }
}

Result

Speaking the ON and OFF phrases to Google Assistant switched the appliance through the relay without touching any button or screen. The command passed through IFTTT and Adafruit IO to the ESP32 within a short delay.

Learnings

  • Cloud services can be chained. IFTTT works as the link between a voice assistant and an MQTT feed.
  • The ESP32 code stays the same no matter what sends the data, as long as it writes to the feed.
  • A relay with an optocoupler keeps the ESP32 circuit electrically separate from the appliance side.
  • Many relay modules are active-LOW, so the pin logic is inverted and the pin must be set to OFF at startup.
  • The mains side is wired only with the power disconnected and kept apart from the ESP32 wiring.
  • Voice commands depend on the internet, so they work only while the Wi-Fi and the cloud services are running.
